# Justified exceptions

Each exception has a scope, a reason, an owner and a review date. Owner of all entries: Joshua
Small (repository owner). Added 2026-11-05; review all by **2027-05-05** or when the cited
condition changes.

| #   | Exception                                                                    | Scope                                                                                        | Reason                                                                                                                                                                                                                                                                                                                                                                                         | Review trigger                                                                               |
| --- | ---------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| 1   | CSP `style-src 'unsafe-inline'`                                              | `vercel.json`, every path                                                                    | Mantine and React `style` attributes set inline styles at runtime; nonces or hashes are not available for a static Vercel site without a server render. Scripts stay `'self'` plus `https://w.soundcloud.com`, with no `unsafe-inline` or `unsafe-eval`, so injected markup still cannot run script (tested in `e2e/security.spec.ts`)                                                         | Moving off runtime inline styles, or to a server that can issue nonces                       |
| 2   | Unknown paths answer 200 with the page                                       | `vercel.json` SPA rewrite                                                                    | One-page site: every path shows the home page, and the canonical link points search engines at `/`, so stray paths are not indexed as copies (tested in `e2e/journeys.spec.ts`). A designed 404 page would be new UI, out of scope here                                                                                                                                                        | Adding a second route or a 404 design                                                        |
| 3   | CodeQL skipped on fork PRs                                                   | `ci.yml` `codeql` job and gate                                                               | Fork tokens cannot upload results. The gate accepts exactly this skip and no other                                                                                                                                                                                                                                                                                                             | Moving the repository to an organization with merge queue, or accepting outside contributors |
| 4   | Playwright excluded from Dependabot                                          | `.github/dependabot.yml`                                                                     | Pinned to the browser build preinstalled in the cloud development environment; a mismatched version cannot find its browser there                                                                                                                                                                                                                                                              | Each Playwright release: bump `@playwright/test` and `playwright-core` together by hand      |
| 5   | Rate limit is per function instance                                          | `server/routes/contact.ts`                                                                   | In-memory and reset by cold starts; a shared store would need a paid or new service (free tiers only). Resend's 100/day cap is the hard backstop                                                                                                                                                                                                                                               | Abuse showing up in Resend, or a free shared store becoming available                        |
| 6   | Production is served before CI finishes, until Deployment Checks is on       | Vercel project setting                                                                       | Vercel's Deployment Checks are configured in the dashboard, not the API this agent can reach                                                                                                                                                                                                                                                                                                   | Owner enables Deployment Checks for `gate` (see requirements-evidence.md, B1)                |
| 7   | `deployment_status` workflows run the workflow file from the deployed commit | `smoke.yml`                                                                                  | GitHub's behavior for this event: a preview deployment of a PR branch runs that branch's copy of `smoke.yml`. Vercel only deploys branches pushed to this repository (fork deployments need authorization), the workflow holds no secrets, and its only write scope is `issues: write`. The production job condition also requires environment `Production`, which Vercel only uses for `main` | Accepting outside collaborators with push access                                             |
| 8   | gitleaks allowance for SoundCloud share tokens                               | `.gitleaks.toml`: the token pattern only, in `src/content/releases.ts` and `src/lib/site.ts` | Private sets play only through their `secret_token`, which the browser must have, so it is public whenever the site is. Leaking it lets someone hear an unlisted album, which the site already allows                                                                                                                                                                                          | An album becoming truly private, or a token appearing in any other file (which still fails)  |

No `npm audit` advisories are excluded: the audit runs at `moderate` with no allowlist.
